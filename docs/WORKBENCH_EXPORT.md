# Локальный рабочий набор редактора

`qazfund-workbench.v1` превращает публичный экспорт возможностей в небольшой
проверяемый пакет для контентной команды. Это локальный инструмент: он не
создаёт учётные записи, не сохраняет пользовательские подборки на сервере и
не включает уведомления.

## Быстрый запуск

По умолчанию команда читает компактный публичный NDJSON на русском языке:

```bash
make workbench-export WORKBENCH_OUTPUT=output/workbench
```

Для точечного набора можно передать локальный файл или URL и фильтры:

```bash
PYTHONPATH=. .venv/bin/python -m scripts.export_workbench \
  --input 'https://qaz.fund/opportunities.ndjson?lang=ru&limit=5000&compact=true' \
  --output output/ai-open \
  --query "искусственный интеллект" \
  --tag kazakhstan \
  --lifecycle open \
  --deadline-after 2026-09-01 \
  --limit 100
```

`--input -` читает NDJSON из стандартного ввода. Пустые строки допустимы,
ошибка JSON с номером строки останавливает экспорт. При фильтре
`--deadline-after` записи без известного срока исключаются, чтобы редактор не
принял неизвестную дату за будущий дедлайн. Значения `--tag`, `--source` и
`--lifecycle` сопоставляются с каноническими значениями публичного экспорта,
например `kazakhstan`, а не с переводом подписи в интерфейсе.

## Что создаётся

В каталоге результата появляются три файла:

- `workbench.json` – контракт `qazfund-workbench.v1`, фильтры, список `id`,
  хеш выборки и безопасные нормализованные записи;
- `opportunities.csv` – те же записи в форме для таблиц;
- `README.md` – короткая передача набора и список официальных страниц.

Проекция разрешает только публичные поля: название, описание, источник,
условия, сроки, ссылки, оценку, стадию, состояние доказательности и небольшой
профиль происхождения. Поле `raw` и неизвестные вложенные поля никогда не
переносятся. Поэтому экспорт можно передавать редактору, не раскрывая
служебные ответы адаптеров, ключи или пользовательские сведения.

## Воспроизводимость и безопасность

Порядок записей стабилизирован по сроку, названию и `id`. В `selection.hash`
попадает каноническое содержимое выбранных безопасных записей, а не время
экспорта. Один и тот же публичный вход и фильтры дают одинаковый хеш даже при
другом порядке строк во входном файле.

Существующие `workbench.json`, `opportunities.csv` и `README.md` не заменяются
без явного `--force`. Перед публикацией или подготовкой заявки проверяйте
условия и форму подачи на официальной странице источника: QAZ.FUND не выдаёт
гранты и не принимает заявки.

## Проверка

```bash
PYTHONPATH=. .venv/bin/pytest -q tests/test_workbench.py
make lint
```

Инструмент не является публичным маршрутом и не меняет продакшн-базу. Публичный
машинный вход остаётся `/opportunities.ndjson`; при изменении его контракта
сначала обновляется этот локальный экспорт и его тесты.
