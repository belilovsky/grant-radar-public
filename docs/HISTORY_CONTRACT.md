# QAZ.FUND public opportunity history

Схема `history.v1` публикуется по адресу
`/opportunities/{id}/history.json?lang=kk|ru|en&limit=50`.

## Назначение

История показывает только изменения нормализованных публичных полей карточки.
Она помогает проверить, когда и что изменилось в опубликованной записи, но не
делает выводов о праве на участие, качестве заявки или вероятности получения
поддержки.

## Политика хранения

- Для существующих записей создаётся одна версия `initial` при миграции.
- Новая версия появляется только при изменении нормализованного публичного поля.
- Обычный повторный запуск парсера без изменения содержания не создаёт новую
  версию.
- В историю не попадают исходный HTML, служебный payload парсера, операторские
  заметки и данные подписчиков.
- `observed_at` означает момент, когда изменение было замечено системой; это не
  самостоятельное подтверждение организатором.

## Ответ

```json
{
  "schema_version": "history.v1",
  "status": "ready",
  "opportunity_id": "…",
  "current_version": 2,
  "version_count": 2,
  "field_coverage": {"deadline": true},
  "items": [
    {
      "version": 2,
      "observed_at": "2026-08-04T12:00:00",
      "content_hash": "sha256:…",
      "changed_fields": ["deadline", "summary"],
      "fields": {"deadline": "2027-04-01"}
    }
  ]
}
```

`status=not_available` означает, что backend истории не подключён или для
карточки ещё нет зафиксированного снимка. Пустые значения остаются пустыми и не
заменяются предположениями.

## Поля версии

`source`, `source_url`, `type`, `title`, `summary`, `funder`, `amount_min`,
`amount_max`, `currency`, `deadline`, `eligibility`, `tags`,
`opportunity_status`, `lifecycle`, `application_url`, `deadline_policy`.

История хранит значения в канонической форме источника. Параметр `lang` меняет
подписи состояния и причину недоступности, но не создаёт автоматический перевод
исторических значений.

## Ограничения и следующий шаг

История изменений не заменяет проверку официальной страницы. Для полноценной
архивной шкалы потребуется отдельный разрешённый архивный контур QazLake с
политикой хранения и удаления; текущий endpoint остаётся публичным read-only
представлением QAZ.FUND.
