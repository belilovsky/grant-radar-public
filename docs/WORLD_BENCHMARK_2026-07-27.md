# QAZ.FUND world benchmark

Дата: 2026-07-27

## Что уже есть

QAZ.FUND уже не просто витрина грантов. В текущем продукте есть каталог с фильтрами, публичные страницы возможностей, профили источников, статус данных, OpenAPI, `llms.txt`, `site-discovery.json`, JSON/NDJSON-экспорт, локальные сохранения, рабочие этапы, CSV, календарь, копируемая справка и связь с QazStack 1.41.2 и AV DS 4.2.0.

Граница продукта остаётся правильной: QAZ.FUND помогает найти программу, проверить источник и подготовить следующий шаг. Он не принимает заявки, не подтверждает право на участие и не прогнозирует одобрение.

## Приоритеты расширения

1. Проверка перед решением на странице возможности: известные факты, недостающие проверки, официальный маршрут и граница вывода.
2. Профиль потребности без аккаунта: роль, регион, тип организации, формат поддержки, горизонт срока; результат – воспроизводимая ссылка.
3. История изменений источника: `observed_at`, checksum, diff summary, статус изменения. Показывать только доказанные изменения.
4. Сравнение выбранных возможностей: только по полям с достаточным покрытием; отсутствующие значения помечать как отсутствующие, не как худшие.
5. Экспорт сохранённого набора в краткий отчёт: таблица, календарь, источники, caveats, дата проверки.
6. Agent/API layer: публичные actions `search`, `inspect`, `qualify`, `export`, которые не требуют персональных данных.

## Что не делать сейчас

- Аккаунты, командные роли, документы, email-уведомления и напоминания без модели согласия, хранения и удаления.
- Юридический eligibility-verdict.
- AI-тексты заявки или прогноз шанса получения финансирования.
- Карту регионов без проверенных координат или официальной геометрии.
