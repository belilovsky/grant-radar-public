# Обмен QAZ.FUND и QazStack

QAZ.FUND использует QazStack 1.41.2 из проверяемого пакета с фиксированной
контрольной суммой. В общий слой перенесены два блока, пригодные для других
каталогов возможностей:

1. Публичная схема `OpportunityV1` с происхождением данных, оценкой полноты,
   локализованными полями и стабильной ревизией набора.
2. Оценка ранжирования по экспертной разметке: точность, полнота, nDCG,
   разнообразие источников, доли ошибок, срезы покрытия и закрытые по умолчанию
   условия выпуска.

В QAZ.FUND сохранены правила, которые нельзя выдавать за общую инфраструктуру:

- соответствие Казахстану и Центральной Азии, веса и пороги;
- сборщики, разбор источников и расписания обновления;
- редакционные тексты на русском, казахском и английском;
- толкование права на участие, решение о публикации и уведомления;
- представление страниц и связь с AVDS.

`core/public_contract.py` теперь отвечает только за преобразование локальной
модели в общую схему. `core/ranking_evaluation.py` сохраняет прежние
идентификаторы QAZ.FUND, но передает вычисления общему модулю. Внешние адреса и
формат действующего интерфейса не меняются.

Проверка выпуска:

```bash
shasum -a 256 -c vendor/qazstack-1.41.2.sha256
.venv/bin/python -m pytest -q
python -m scripts.production_smoke --base-url https://qaz.fund
```

Рабочая версия и точная ревизия QazStack публикуются по адресу
`/.well-known/qazstack-consumer.json`.
