# QAZ.FUND comparison read model

Схема `comparison.v1` публикуется по адресу `/compare.json`. Она позволяет
сопоставить от двух до четырёх карточек по тем полям, которые уже есть в
открытом каталоге.

## Правила

- идентификаторы передаются через `ids=id1,id2[,id3,id4]`;
- `lang=kk|ru|en` меняет только язык интерфейсных подписей и локализованных
  полей карточки;
- пустое поле возвращается как `Not published` / `Не указано` /
  `Көрсетілмеген`, а не заменяется предположением;
- в `field_coverage` для каждого поля указаны фактические `present`, `total` и
  `ratio`;
- `status=ready` означает, что найдены минимум две карточки, а
  `status=partial` – что часть запрошенных карточек отсутствует;
- сравнение не является юридической проверкой права на участие и не ранжирует
  программы по вероятности получения средств.

## Поля карточки

Сейчас read model отдаёт организатора, источник, формат, статус, срок, сумму,
аудиторию, темы и официальный URL. В каждой карточке также остаются заголовок,
описание и список `unknown_fields`.

## Следующий визуальный слой

HTML-маршрут `/compare` зарезервирован в discovery-контракте. Его можно включать
после визуальной сборки AVDS4-компонента сравнения; текущий JSON уже пригоден для
ИИ и внешних интерфейсов и не требует отдельного хранилища.
