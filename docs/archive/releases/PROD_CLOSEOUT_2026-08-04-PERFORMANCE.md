# QAZ.FUND — закрытие релиза производительности, 4 августа 2026

## Публичное подтверждение

На `https://qaz.fund` ответ каталога `/opportunities` при поддержке gzip уменьшился примерно с 1,29 МБ до 88 КБ по сети (`Content-Encoding: gzip`, `Vary: Accept-Encoding`). Публичный release marker подтверждает тот же кодовый релиз.

## Ограничения

Сжатие снижает сетевую передачу, но не заменяет дальнейшую оптимизацию холодного формирования каталога. Время серверного расчёта и кеширование остаются отдельными задачами следующего прохода.
