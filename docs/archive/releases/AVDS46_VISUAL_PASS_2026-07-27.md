# QAZ.FUND AV DS 4.6 visual pass

Дата: 2026-07-27

Выпуск переводит публичные страницы QAZ.FUND на компактную композицию AV DS
4.6.0. Главная страница получила единый первый экран, полосу доверия, плотные
фильтры и двухколоночный каталог на широких экранах. Карточки программ больше
не содержат вложенной служебной панели.

Страница программы построена как единая полоса чтения с редакционным первым
экраном. Повторяющиеся предупреждения объединены в раздел «Ключевые условия»,
длинная выдержка из первоисточника раскрывается по запросу, а технические оценки
QazCompute не показываются в публичном тексте.

В разметке закреплены `TrustStrip`, `EditorialLeadRail`,
`LiteReadingSurface`, `QuickLinksRail`, `PublicSummaryStrip`,
`TrustFactsPanel` и `DocumentCard`. Серверный адаптер остаётся локальным; прямой
импорт React-пакета не заявляется.

Одновременно опубликованы отдельные контракты QazPipe и QazCompute. QazPipe
получает версионированный источник только для чтения с правилами контрольных
точек, происхождения и повторной обработки. Передача в QazLake остаётся
управляемой и не включает прямую запись из QAZ.FUND. Четыре профиля QazCompute
исполняются локально и воспроизводимо; удалённый исполнитель не заявляется как
подключённый.

Проверка выпуска включает полный набор тестов, редакторский поиск, снимки
шириной 1440 и 393 пикселя, контроль переполнения, проверку консоли браузера и
повторную проверку публичных маршрутов после развёртывания.
